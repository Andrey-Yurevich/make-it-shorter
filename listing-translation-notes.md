# Перевод листинга: название, краткое и полное описание

Источник: Batch 23, групповая встреча #3, 22.06.26.

## Автоперевод — обязателен

- Продукты переводятся на 52 языка. Автоперевод делают все, без вариантов; после него уже можно публиковаться.
- Инструмент — Localiz Camp. Секретный ключ бесплатный на время буткэмпа, лежит в мануале.
- Вставить название, краткое и полное описание английской версии, ввести ключ — переводит примерно за час.
- На части редких языков ChatGPT вместо перевода пишет одно и то же слово подряд. Это переспам, он убивает SEO (так потеряли несколько расширений). Для таких языков Localiz Camp переводит через Google. Каждый язык всё равно перепроверить.
- ChatGPT не держит лимит краткого описания в 132 символа: превышает (Chrome обрежет при загрузке) или пишет короче. Ключи на части языков тоже теряет. Этим можно пренебречь: конкуренция на других языках меньше.
- Мануал по BabelEdit устарел, оставлен для истории.

## Архив и манифест

- Localiz Camp отдаёт архив, языки в нём уже разложены в правильной структуре.
- Технически переводы — отдельные файлы в папке локалей в билде.
- Проверить, что в манифесте стоят правильные переменные на переводы. Иначе в сторе 52 раза продублируется английский: 52 дубликата — смерть для SEO на старте.
- Полное описание в `manifest.json` не указывается, но переменная со ссылкой на него заводится, чтобы её подхватил скрипт автозагрузки в стор.

## Загрузка в Chrome Web Store

- Название и краткое описание подтягиваются из архива сами.
- 52 полных описания Chrome не подтягивает. Вместо ручного копипаста — скрипт, который берёт их из архива и заполняет все языки.

## Ручная доработка до публикации

Желательно успеть до публикации. Порядок: название → краткое описание → в идеале полное описание.

### Языки

Две группы, полный список в мануалах:

1. **Платящие:** Франция, Германия, Испания, Италия, Нидерланды, Норвегия, Швеция, Португалия; корейский и японский тоже сюда. Конкуренция там несопоставимо меньше, чем в англоязычном и русскоязычном сегментах.
2. **Много носителей:** русский, арабский, турецкий, вьетнамский. Пользователи из любой страны поднимают показы в поиске по всему миру, в том числе в платящих странах.

Хинди не входит: в Индии ОС и браузер в основном на английском. Китайский не входит: у Китая своя экосистема браузеров, а китайцев за рубежом с Chrome меньше, чем, например, арабоязычных.

### Название

- Перевести название через ChatGPT, искать аналоги в Semrush.
- По неанглоязычным странам у Semrush данные скудные: запросы на национальных языках занижены примерно в 10 раз, поэтому их цифру умножать на 10. Исключение — русский: Яндекс Wordstat, бесплатно.
- Где искать местные варианты: выдача по стране в Semrush; Chrome Web Store с параметром `?hl=es` (локаль), там смотреть переводы у конкурентов. Их мало: 30+ переводов есть примерно у 4% расширений.
- Сравнить по стране частотность английского запроса (как есть) и национального (×10):
  - различие меньше 10 раз → оба ключа через дефис, национальный первым: `<национальный> - <английский>`. На английском так на старте не делать;
  - английский больше в 10+ раз → оставить английский;
  - национальный больше в 10+ раз → только национальный.
- Пример, Испания, color picker: английский 12 100, испанский 720 × 10 = 7 200 → оба ключа.
- Грамотность написания прогнать через ChatGPT.
- Проверки, которые делали для английского (занят ли запрос хорошо оптимизированным конкурентом и прочее), для этих языков не делают.

### Краткое описание

- Попросить ChatGPT переписать автоперевод из Localiz Camp с ключами из нового названия, в пределах 132 символов.

### Полное описание

- Не переписывать. В переводе заменить оригинальный ключ из названия на ключ, подобранный вручную.
- Отдельный подбор ключей через Semrush под полное описание на каждом языке не делать. Можно как эксперимент после буткэмпа.

## Что не переводят на старте

- Welcome page, интерфейс, скриншоты. Описания люди не читают, а интерфейс и welcome page читают. Плохой перевод (кнопка Save стала «Спасти») рушит поведенческие факторы, и, не зная языка, причину не найти.
- Локализуют, когда продукт закрепился в поиске: 2–3 недели на вычитку и перепроверку, в идеале с носителями.
