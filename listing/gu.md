# Gujarati (gu)

## Name
Make It Shorter — Make It Shorter
not a priority market

## Short description
AI ની મદદથી એક ક્લિકમાં લખાણ ટૂંકું કરો અને સારાંશ મેળવો — વાક્ય હોય કે આખો લેખ. બસ પેસ્ટ કરો, ગમે તે ભાષા ચાલશે.
Shorten text in one click with the help of AI and get a summary — be it a sentence or a whole article. Just paste it, any language will do.

## Blind read
- Short description: chatty "બસ પેસ્ટ કરવાનું" → plain imperative "બસ પેસ્ટ કરો".
- "Pull in the whole page again": "reload the page" (read as a browser refresh) → "bring the whole page's text into the panel again".
- Step 4: "watch the result being written" → "watch the result take shape".
- Lists line: fragment "same points, each a bit shorter" → full clause.
- Pictures line: "the article's photos" → "each photo of the article stays with its paragraph".
- Long/short paragraph sentences: smoother verbs ("shrinks into its key points", "every point is kept").
- Settings heading: wrong gender agreement and clumsy relative clause fixed.
- Language setting: "અનુવાદક" (a human translator) → "no need to translate separately".
- Study use: "seminar" → "class", which is more usual for Indian students.
- Research use: rewritten as an instruction like the other uses, dropping the calque "reading list"; "Looking things up" label made a noun like the others.
- Caveat paragraph: "worth giving twenty minutes" → "worth spending twenty minutes on"; "decision rests on a detail" made idiomatic; "AI works inside" (calque of "under the hood") → "this is an AI-based tool".
- Limits: daily limit put as "free, but usable only a certain number of times a day per device".
- FAQ: doubled "હજી" → "વધુ"; repeat-pass answer reworded; Simplified answer no longer ends in a fragment; "next time" fixed ("આગલી" means previous → "આવતી").
- Misspelling FAQ: kept as the Gujarati typing variants "ટુંકુ" / "સારાંસ", reworded so it reads less like it was written for search.
- Closing line: was an unfinished sentence → complete sentence, without repeating the verb.
- Rejected: replacing Chrome's own localized name "Chrome વેબ દુકાન" with the English "Chrome Web Store".
