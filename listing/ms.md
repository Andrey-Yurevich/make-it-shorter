# Malay (ms)

## Name
Make It Shorter — Make It Shorter
Not a priority market: the Semrush database is `none`, so Semrush was skipped. The wording comes from general knowledge of Malaysian Malay. The main verbs are "pendekkan / memendekkan" (shorten) and "ringkaskan / ringkasan" (summarize / summary), with "ringkas dan padat" for "short and to the point". The text addresses the reader as lowercase "anda" throughout. It uses Malaysian number formatting (30,000) and uses Malaysian forms instead of Indonesian ones (saja → sahaja, tidak ada → tiada, tempel → tampal, jendela → tetingkap, browser → penyemak imbas, akun → akaun).
Unverified Chrome terms: web fetch and search were not permitted in this session, so the names of Chrome's own parts come from memory. They are "bar alat" (toolbar), "panel sisi" (side panel), "Kedai Web Chrome" (Chrome Web Store), "pemapar PDF terbina dalam" (built-in PDF viewer), "sematkan" (pin), "sambungan" (extension) and "penyemak imbas" (browser). Each is a one-word fix if wrong.
Misspelling FAQ: "summerize" was replaced with a real Malay typo, "pendekan" for "pendekkan" (shorten): people drop the doubled k before -kan.

## Short description
Pendekkan ayat atau seluruh artikel dan buat ringkasannya dengan AI. Tampal teks, klik sekali, dapatkan hasil dalam apa jua bahasa.
Shorten a sentence or a whole article and make a summary of it with AI. Paste text, one click, get the result in any language.

## Blind read
- Short description: "seluruh tulisan" (whole writing) became "seluruh artikel" (whole article).
- Opening: "sedikit masa" (a calque of "little time") became "masa terhad" (limited time). "Dikembalikan" (returned) became "diubah menjadi" (turned into).
- How it works: "bahasa hasil" (result language) became "bahasa ringkasan" (summary language). "Written before your eyes" became "appears live".
- List items: "each shorter" was smoothed. The circular sections line became "sections in the document are kept". The pictures line "beside" became "together with" (their paragraphs).
- "How short" became "the degree of shortening depends on your original text". The closing clause became "important points stay intact".
- Settings: the heading became "Two settings, pick once". The language item became "summarize and translate at once".
- Uses: the dictionary word for "thread" (bebenang) became "rantaian perbualan" (conversation chain). "Forward" became "sent on to someone else". "First pass" became "initial screening".
- "Deserves twenty minutes", "when a detail decides" and "AI underneath" were reworded. The last became "this tool is powered by AI".
- Limits: "Summarizing is free" became "Free to use", fixing a textbook grammar error. "There" became "for pages like these".
- FAQ: "each pass" was reworded. The Simplified answer was de-duplicated. The chat question became colloquial "sampai muat untuk mesej chat" (until it fits a chat message). "Run it once more" became "press Shorten once more". "Pictures of words" became "text in images". "Retelling" became "rewritten in other words". "Typo" was rephrased. A grammar slip "gunakannya" was fixed to "menggunakannya".
- Declined: "thread" as an English loan and "rantaian e-mel" (it would add "email"); "ringkaskan sebelum di-forward" (it would drop "straight to the point"); dropping the AI-papers mention (it would drop a claim); "kertas penyelidikan" (it would repeat the line's "Penyelidikan:" label).
