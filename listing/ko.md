# Korean (ko)

## Name
AI 글 요약 — AI text summary
Priority market. Semrush, database `kr`: `make it shorter` 30/month; best national phrasing `요약 ai` 1,600 (×10 = 16,000, over 500× ahead). Rule: national 10× or more ahead → national phrasing alone. Much of the `요약 ai` traffic is people summarizing YouTube videos (related queries: Lilys, 유튜브 요약 ai), so the name adds 글 ("text") to say it works on text. It keeps both search words, 요약 and AI, so it should also catch `ai 요약` (1,000). Secondary keywords: `글 요약` / `텍스트 요약` (110 each) render "text summarizer", `기사 요약` (110) "article summarizer", `논문 요약` (720, `논문 요약 ai` 2,900) "summarize ai papers". The shortening phrases (make it shorter, make it short…) are rendered with 줄이다 / 짧게 so that 요약 is not repeated in every line. Since the name is also the toolbar icon's title, step 1 points at the icon "AI 글 요약"; elsewhere the product stays Make It Shorter.
The misspelling FAQ (`summerize`/`summerizer`) is dropped. Korean has no common misspelling of 요약, only typing it in the wrong keyboard layout (`dydir`), which would read oddly as a FAQ.
Chrome's Korean terms (툴바, 측면 패널, 고정, Chrome 웹 스토어, PDF 뷰어) come from memory. Checking them against Chrome help or Chrome's own files was not permitted in this session.

## Short description
AI 글 요약으로 짧은 문장부터 긴 문서까지 간결하게 줄여 보세요. 텍스트를 붙여 넣고 클릭 한 번이면 원하는 언어로 정리됩니다.
Shorten anything from a short sentence to a long document with AI text summary. Paste your text, and one click tidies it up in the language you want.
