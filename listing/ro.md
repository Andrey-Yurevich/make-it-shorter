# Romanian (ro)

## Name
Make It Shorter — Make It Shorter
Not a priority market. Wording comes from common Romanian usage: «rezumat» / «rezumă» (summary / summarize), «scurtează» (shorten), «generator de rezumate» (summary generator). The misspelling FAQ uses «sumarizare», the anglicized variant of «rezumare», because it is a variant people really type. Chrome's Romanian terms (Magazinul Chrome Web, bara de instrumente, panou lateral, fixează) come from memory: web lookup was not approved in this session.

## Short description
Rezumă texte întregi sau scurtează doar o frază cu AI, în orice limbă. Lipește conținutul și ai rezultatul dintr-un clic.
Summarize whole texts or shorten just one sentence with AI, in any language. Paste the content and get the result in one click.
