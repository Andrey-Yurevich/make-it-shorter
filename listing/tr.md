# Turkish (tr)

## Name
Yapay Zekâ ile Özet Çıkarma — Summarizing with AI
Priority market. Semrush, database `tr`: `make it shorter` returned no row at all (other zero-volume phrasings did come back as 0), so treated as 0/month. Best national phrasing «özet çıkarma» ("making a summary") 720, plus its form typed without Turkish letters «özet çikarma» 2,900, about 3,600 in all (×10 far beyond 0). Rule: national 10× or more ahead → national phrasing alone. «metin özetleme» ("text summarization", 170) and «özetleme» (1,000, a single generic word) ranked lower; shortening phrasings («metin kısaltma», «paragraf kısaltma», «yazı kısaltma») have 0–30. Bare «Özet Çıkarma» does not say what kind of tool it is, so it is extended with «Yapay Zekâ ile» ("with AI") for clarity. It echoes the search «özet çıkaran yapay zeka» (720) only if the store treats â as a; «Zekâ» is the standard spelling. In the full description the name's keyword replaces the brand in step 1 of "How it works" ("to summarize, click the extension icon…"). Not used: «pdf özetleyici»/«pdf özetleme» (the built-in PDF viewer cannot be read, so it would be a false claim), book-summary searches (people want ready-made school summaries), the competitor «resoomer», and English «summarize» (720).
The misspelling FAQ uses «ozet cikarma», the same search typed without Turkish letters.
